# DeskSpacing v1.0 distribution and provenance ledger

Review date: 2026-11-16. Scope: this checkout on `chore/v1-release-readiness`,
the current `dist/` generated by `npm run build`, and repository evidence. This
is an evidence inventory, not a legal opinion or authorization to publish.
**A-002 remains open.** The release owner must decide rights and the final file
set before distribution.

## What the build ships

`vite.config.js` disables automatic `public/` copying. Vite emits the home,
planner and share-link bundles; `scripts/legacy-site.js:copySite()` copies the
two root HTML pages, every `scripts/site-layout.js` mount except its explicit
overrides/retired scripts, selected npm dependencies, `THIRD_PARTY_NOTICES.md`
and `.nojekyll`. It does not copy `README.md`, this ledger, test fixtures,
`vendor/three/`, `node_modules/` as a tree, `.git/`, CNAME or legacy SCSS.
The package to review is **`dist/` only**.

The inspected build contains **463 files / 1,214,206,675 bytes (1,157.96 MiB)**.
These counts include hidden files and are a snapshot, not a hosting guarantee.
The output includes 232 GLBs and three glTF JSON files.

## Potential reductions, without changing this build

- **Clear non-runtime candidates:** `css/.DS_Store`, `images/.DS_Store`,
  `fonts/.DS_Store`, and `Model thumbnails/favicon paintnet.pdn` have no
  browser references in current HTML/CSS/JS. A future packaging rule could omit
  them after a build regression. They are presently still in `dist/`.
- **Exact duplicate bytes:** SHA-256 comparison found 21 duplicate groups,
  including seven model pairs, ten thumbnail pairs, a demo glTF pair and the
  three `.DS_Store` files. Examples: `GLTFs/music objects/microphone 1.glb`
  versus `GLTFs/music objects/blue yeti.glb`, and
  `desks/standing_desk_1_reference_plane.glb` versus its `GLTFs/` counterpart.
  Duplicate bytes do not make either public URL removable. Check catalog IDs,
  legacy dictionaries, shared links, sidecars and rights before any exclusion.
- **Likely historical/demo candidates:** `3d/scene.gltf` has no literal runtime
  reference found and lacks sidecars at its own relative path; `myDeskSETUP.gltf`,
  prototype routes and many `GLTFs/` entries likewise lack direct literal
  references in active code. Dynamic loading and historical URLs prevent a safe
  bulk exclusion conclusion. Retained HTML pages and route tests explicitly
  expect the prototype routes. Confirm compatibility policy first.
- The five optimized GLBs **do not replace publication rights** for their
  originals. Current modern startup uses the optimized URLs while originals
  remain available for historical routes and for preserved source comparisons.

## Release-owner decisions required

1. Establish a redistribution basis for original application code and design,
   and approve the exact `dist/` contents for publication.
2. For every inherited model, texture, font, image, tutorial file and demo,
   obtain source/creator, exact license or permission, required credit and
   modification evidence. Record unsupported items for authorized replacement
   or exclusion with route/link compatibility reviewed.
3. Verify the four named CC BY model sources and matching thumbnails, the demo
   glTF attribution/sidecars, archived addons, and GSAP terms; retain all
   required notices in the final package.
4. Decide whether historical/prototype routes and unreferenced collections
   remain in v1. Any exclusion needs URL/sidecar/reference tests and an explicit
   compatibility decision. Do not silently remove legacy shared-link targets.

Until these decisions and the missing evidence are recorded, **A-002 is open and
the current complete `dist/` is not approved by this ledger for public release**.

## Validation performed

The focused `tests/unit/build.test.js` and `tests/unit/catalog.test.js` checks
passed (4 tests). A local reference scan found 11 CSS `url(...)` references and
no missing local CSS target. The four non-runtime candidate files above have
zero literal references across current HTML, application/legacy JavaScript and
CSS. The root demo glTF's two relative sidecars exist; the two relative sidecars
of `3d/scene.gltf` do not. SHA-256 comparison found the duplicate groups listed
above. Literal-reference scans cannot prove that dynamically assembled URLs or
historical external links are unused. No asset was removed or excluded.
