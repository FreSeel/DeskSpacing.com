About DeskSpacing v1.0

DeskSpacing is a 3D desk setup planner. This maintained fork builds on the original project by Cooper Lappenbusch and Travers Sorenson.

There is no published direct support email or social account for this fork. View the fork source on GitHub.

Original project creators

Cooper Lappenbusch
Original project programming

Worked on the programming side of the project utilizing the ThreeJS JavaScript library.

Travers Sorenson
Original project 3D modeling

Modeled and textured objects for the original project and contributed to its website design.

Technologies Used

The planner uses these technologies

Bootstrap 5

Bootstrap supports the planner interface.

ThreeJS

Three.js loads and displays 3D models in the browser.

blender

Blender was used for original project 3D modeling.
